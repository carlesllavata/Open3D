Open3D Launcher portable mode

While this file sits next to open3d-launcher.exe, Open3D Launcher keeps its settings, its
download cache and its record of installed apps in the Open3DLauncherData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move Open3D Launcher with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Open3D Launcher) instead.
If Open3DLauncherData can't be written (for example on a read-only drive), Open3D Launcher says
so and uses %APPDATA%\Open3D Launcher instead.
